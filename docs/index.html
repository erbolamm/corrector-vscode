🧠 +150 reglas de corrección

Confusión b/v, h omitida, c/s/z, g/j, ll/y, tildes automáticas, n→m ante b/p, abreviaturas de chat y transposiciones.

🔌 100% offline por defecto

El motor de corrección no depende de ningún servicio externo. El modo IA opcional es el único que reenvía texto a Copilot, y tú lo activas expresamente.

♿ Pensado para dislexia

Fuente OpenDyslexic conmutable, explicaciones de cada corrección y un flujo pensado para no sobrecargar.

📥 Descarga segura de modelos

El panel de IA local valida el identificador contra una lista permitida, descarga a un archivo temporal, comprueba integridad y solo entonces renombra al destino final.

🧮 Comprobación de memoria previa

Antes de cargar un modelo local, se calcula si hay RAM suficiente. Si no la hay, avisa y no carga: nunca deja el equipo sin responder.

📖 Diccionario personal

Añade tus propias correcciones y palabras a ignorar; se aplican antes que las reglas generales.

Cómo funciona

  1. Instala la extensión desde VS Marketplace u Open VSX.
  2. Abre el chat de Copilot (Ctrl+Shift+I / Cmd+Shift+I).
  3. Escribe @corrector seguido de tu texto.
  4. El corrector devuelve el texto corregido, con cada cambio explicado.
  5. Si quieres, pulsa el botón para reenviarlo tal cual a Copilot.
  6. Opcional: abre el panel de IA local para corrección offline con un modelo propio.
¿Corrige otros idiomas además del español?

No. El motor de reglas es exclusivamente para español; otros idiomas no se detectan ni se corrigen.

¿El modo IA consume mi plan de Copilot?

Solo si activas corrector.reenviarACopilot. Por defecto está apagado y la corrección ortográfica es siempre gratuita y offline.

¿Se guarda o se envía mi texto a algún servidor?

No, salvo que actives el modo IA (reenvío a Copilot) o cargues un modelo remoto. La corrección offline y el panel de IA local se quedan en tu máquina.

Instalación

Un solo comando si tienes el CLI de VS Code instalado, para macOS, Windows y Linux por igual.

code --install-extension apliarte.corrector-espanol

En Windsurf, Antigravity o Cursor (usan Open VSX, no el Marketplace de Microsoft):

# 1. Descarga el .vsix desde GitHub Releases
# https://github.com/erbolamm/corrector-vscode/releases
# 2. Paleta de comandos → "Extensions: Install from VSIX..."
# 3. Selecciona el archivo descargado
